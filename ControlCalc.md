Control System Calc (ControlCalc) is an engineering tool for control engineers, R&D staff and students. Enter a transfer function to perform PID tuning, frequency-domain analysis and time-domain simulation — turning textbook control theory into a pocket tool you can use anywhere. All calculations run locally on your device, no internet required.
KEY FEATURES

■ PID Tuning
Five classic tuning methods built in: Ziegler-Nichols open-loop step, Cohen-Coon, Ziegler-Nichols closed-loop ultimate, plus IMC-Lambda and AMIGO. Each method includes guidance on when to use it.

■ Closed-Loop Step Simulation
Simulate the closed-loop step response with an FOPDT model and a PID controller with derivative filtering. View the control effort u(t) to spot actuator saturation, and fine-tune parameters by hand.

■ Bode Plot & Stability Margins
Draw magnitude and phase curves on a log scale, with automatic 0 dB / −180° reference lines, gain margin, phase margin and crossover frequencies — stability at a glance.

■ Step Response & Performance Metrics
RK4 time-domain simulation that automatically computes overshoot, rise time and settling time.

■ Second-Order Designer
Back-solve system parameters from overshoot Mp / settling time ts, or from damping ratio ζ / natural frequency ωn, then push them to the step-response page in one tap.

■ Root Locus & Nyquist (Pro)
Root-locus branch tracing with the imaginary-axis stability boundary, an equal-aspect Nyquist plot with unit circle, plus pole/stability analysis for deeper insight.
